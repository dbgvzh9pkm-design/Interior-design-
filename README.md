# Interior Design

## Installed Claude Code skills

- **banana** (`.claude/skills/banana/`) — brief-led image generation, editing,
  comparison, and review using Google's Gemini image models. Standalone
  install of [AgriciDaniel/banana-claude](https://github.com/AgriciDaniel/banana-claude)
  v3.0.0, invoked from Claude Code as `/banana`. Requires Python 3.11+ and a
  `GEMINI_API_KEY` environment variable for paid execution; planning and
  review run without any provider calls. See `.claude/skills/banana/SKILL.md`
  for usage.
